Keka使用教程：Mac解压rar/7z与压缩包密码处理

发布：2026-11-25分类：压缩工具

软件简介与适用场景

Keka 是 macOS 上一款免费好用的文件压缩与解压工具，常年排在 Mac 效率类工具推荐榜前列。它的特点是「平时不占地方，用时一拖就完」：把 Keka 放在 Dock 里，压缩和解压都只需要把文件拖到图标上，甚至不需要打开主窗口。常见适用场景包括：解压 Windows 同事发来的 rar、7z 压缩包；打包发送邮件附件前把大文件压小；给敏感文件上 AES-256 加密；把超过邮箱或网盘单文件限制的大文件分成多个分卷。它支持的解压格式超过 35 种，包括 7Z、ZIP、ZIPX、RAR、TAR、GZIP、BZIP2、XZ、DMG、ISO、EXE、CAB、MSI、APK、IPA、XIP 等；可创建的格式有 7Z、ZIP、TAR、GZIP、BZIP2、XZ、DMG、ISO、BROTLI、ZSTD、WIM 等。

安装步骤

1. 打开 Keka 官网（keka.io）或 Mac App Store，下载最新版安装包；官网还提供适配旧版 macOS 的历史版本。2. 双击 dmg 文件，把 Keka 拖入「应用程序」文件夹完成安装。3. 首次打开如果提示来自未知开发者，进入「系统设置 → 隐私与安全性」，点击「仍要打开」。4. 建议把 Keka 拖到 Dock 栏长期保留，之后压缩文件直接拖到 Dock 图标即可。5. 如果希望双击压缩包时默认用 Keka 解压，可以使用官网提供的默认应用设置小工具，或选中任意压缩包右键「显示简介 → 打开方式」选择 Keka 并点击「全部更改」。

核心功能操作要点

解压压缩包：把 rar、7z、zip 等压缩包直接拖到 Keka 窗口或 Dock 图标上，文件会解压到压缩包所在目录下的同名文件夹；多个压缩包可以一次性拖入批量处理。压缩文件：打开 Keka 主窗口，先选择格式与压缩等级，再把文件或文件夹拖进来；7z 格式压缩率最高，适合归档大文件。加密压缩：格式选 7z 时在密码框输入密码即使用 AES-256 加密；zip 则是 Zip 2.0 传统加密，兼容性好但强度较低。密码务必自己记牢，官方不提供找回途径。分卷压缩：勾选分卷选项并填写单卷大小（例如 100M、4.7G），压缩后会得到 .7z.001、.7z.002 这样的分卷文件。中文文件名乱码补救：Windows 下用 GBK 编码打包的压缩包，Keka 默认按 UTF-8 解析会出现乱码，打开「偏好设置 → 解压」，把文件名编码改为 GBK 后重新解压即可恢复，解完建议改回 UTF-8 以免影响其他压缩包。另外 Keka 出于跨平台考虑不支持创建 .exe 自解压包，需要发给 Windows 用户时建议用普通 7z 或 zip。

常见问题

问：解压带密码的压缩包怎么做？答：把加密压缩包拖入 Keka，会自动弹出密码输入框，输入正确密码即可开始解压；如果密码来自网页复制，注意开头结尾不要带多余空格，区分大小写。个别很老版本的 WinRAR 加密方式可能无法解开，需要打包方重新压缩。

问：分卷压缩包只能解开第一个卷？答：这是正常现象。.7z.001/.002 或 part1/part2 的所有分卷必须放在同一个文件夹里，解压时只需解编号第一个（.001 或 part1），Keka 会自动识别并串联全部分卷，缺任何一个分卷都会报错。

问：双击压缩包不是用 Keka 打开的？答：选中文件右键「显示简介 → 打开方式」，选择 Keka 并点击「全部更改」；或使用官网的默认应用辅助工具一键设置。安装后也可以在 Finder 的「服务」菜单里直接调用 Keka 的压缩和解压项。
