Geek Uninstaller使用教程：卸载捆绑软件与清理残留

发布：2026-11-12分类：实用工具

Geek Uninstaller 是做什么的，适合谁用

Windows 自带的「程序和功能」只负责把软件主体拆掉，配置文件、缓存目录、注册表项往往原地不动。用得久了，C 盘里堆一堆「已卸载软件的遗物」，装新版本时还会因为旧键值没清干净而出错。Geek Uninstaller 解决的就是这一步：调用软件自身的卸载程序走完正常流程后，再扫描文件系统与注册表，把剩下的列成清单让你确认删除。

它的定位很明确——不做系统优化、不弹窗、不常驻后台，就是一个「卸得干净」的小工具。适合经常试装软件、接手别人电脑做清理、或者只想让硬盘别越用越满的人。整包只有一个可执行文件，体积几 MB，免安装、可放 U 盘，也不写系统服务。

获取与启动：一个 exe，双击就能用

站内提供的是 Windows 版，版本 1.5.4.180，解压后得到单个 Geek Uninstaller 主程序，无需运行安装向导。建议右键「以管理员身份运行」——普通权限下删 Program Files 与 HKLM 下的项会失败，这是新手最常踩的坑。

启动后窗口里直接是已安装程序列表，按名称字母序排列，也可以点表头改按占用空间或安装时间排序。顶部有搜索框，想卸哪个直接敲名字即时过滤。首次使用先改语言：菜单「选项 > 语言」里选简体中文。

把软件卸干净：普通卸载 + 残留扫描

① 右键 > 卸载。最常规的路径。Geek 会拉起该软件自己的卸载向导，按提示点完（遇到「是否保留配置」「是否重启」按需求选）。此时先别急着关 Geek 窗口。

② 等它自动扫描残留。向导结束后立刻扫描，结果分两栏：文件系统（残留的安装目录、AppData 下的配置与缓存）和注册表（软件写入的键值）。默认已勾选，扫出什么、在哪个路径都写得很清楚，逐条看一眼再点「完成」。这是整个工具的核心价值，跳过等于白用。

③ 顺手清条目。若卸载中途报错、软件从列表消失但文件还在，右键还有兜底项：「删除条目」只删列表记录（不动文件），适合清僵尸条目；「安装文件夹」跳到安装位置核对；「注册表条目」定位到该软件的键。

④ 留一份装机清单。「文件 > 导出为 HTML」把当前所有已安装程序导成网页表格，含名称、大小、安装时间，换机或报故障时发给对方比截图靠谱。「查看 > 卸载记录」则保留历史卸载动作。

顽固软件与商店应用：两条备用通道

强制删除（Force Removal）。遇到卸载程序损坏、点了没反应、或者压根没有卸载入口的软件，右键选「强制删除」。它绕过自带卸载程序，直接删关联文件、注册表项，以及注册的服务与驱动。执行前要求输入名称二次确认，扫出的清单同样要人工勾选。这条通道适合流氓软件、装机残留、卸载中途崩掉的半成品；不要用它卸系统组件、运行库和驱动，删错会影响启动。

Microsoft Store 应用视图。按 Ctrl+Tab 切到商店应用列表，Xbox、邮件这类预装 UWP 应用会单独列出来，右键即可正常卸载，不需要强制删除。有些系统级组件即便卸掉，系统更新后可能被重新装回，这属于 Windows 自身行为。

关于版本边界。免费版个人免费，卸载、残留清理、强制删除都在，一次一款。批量卸载、实时监控、启动项管理属付费 Pro 版，日常清理用不到。

常见问题

卸载完软件还在列表里？先去「安装文件夹」看目录是否还在，还在就用强制删除重来一次；文件确实删掉了、只是列表残留，右键「删除条目」抹掉记录即可，不会碰文件。

提示程序正在运行、卸不掉？先退出软件主界面，再检查右下角托盘图标右键退出；带后台服务的（网盘、输入法、安全软件）要在服务管理器里停掉对应服务。若被杀毒软件占用，临时关闭防护再试。

强制删除会不会误删别的东西？它按软件登记的文件与注册表关联扫描，删除前列出清单让你确认，不勾的不会删。稳妥做法是先只勾明显属于该软件的目录与键，拿不准的留着——残留一点比删错系统文件安全得多。
