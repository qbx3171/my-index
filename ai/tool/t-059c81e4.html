DeepSeek

DeepSeek（深度求索）是杭州深度求索人工智能基础技术研究有限公司推出的大模型系列与 AI 助手产品，以开源、高性价比和强推理能力著称。其对话应用（网页端与 App）完全免费，无订阅制、无付费墙，注册即可使用全部核心功能。模型权重以 MIT 协议开源，开发者可免费下载并在本地部署运行。2026 年 4 月，DeepSeek-V4 预览版上线，将 1M（百万）上下文设为官方服务标配，同时开源模型权重。此后 V4.1 Flash 进一步引入原生多模态视觉理解能力。DeepSeek 已从单纯的对话模型发展为覆盖编程、Agent 执行、长文档处理和多模态理解的全能型 AI 平台。

【核心功能】

百万级超长上下文 DeepSeek-V4 全系标配 1M token 上下文窗口，可一次性处理《三体》三部曲体量的超长文本，或数百页合同、整套项目源码。通过全新的注意力压缩机制与 DSA 稀疏注意力，在处理长上下文时大幅降低计算和显存消耗，使百万上下文成为普惠能力而非稀缺资源。

双模型矩阵：Pro 与 Flash DeepSeek-V4 提供两个版本：V4-Pro 为旗舰模型，在数学、STEM、竞赛型代码评测中超越所有已公开的开源模型，世界知识测评大幅领先其他开源模型，仅稍逊于顶尖闭源模型。V4-Flash 为经济高效版本，推理能力接近 Pro，适合日常任务和快速响应场景。两者均支持思考模式与非思考模式，可通过 reasoning_effort 参数调节思考强度（low / high / max）。

Agent 与编程能力 V4-Pro 的 Agentic Coding 能力达到当前开源模型最佳水平，已成为 DeepSeek 内部员工日常使用的编程模型，交付质量接近顶级闭源模型的非思考模式。模型针对 Claude Code、OpenClaw、OpenCode、CodeBuddy 等主流 Agent 产品进行了适配优化，在代码任务和文档生成任务上表现均有提升。

原生多模态视觉理解（V4.1 Flash） 2026 年 9 月发布的 V4.1 Flash 具备原生多模态视觉理解能力，采用全新非对称模型结构，在保持速度优势的同时进一步降低成本。图像理解功能支持通过 base64、URL 或 Files API 传入图片，按 Flash 价格计费。

免费对话与联网搜索 网页端（chat.deepseek.com）和移动端 App 完全免费，包含深度思考模式、文件上传和联网搜索功能，无每日消息配额限制。高峰时段可能出现响应变慢或“服务器繁忙”提示，但功能层面无任何付费门槛。

【如何使用】

方式一：网页端（零门槛） 浏览器访问 chat.deepseek.com，使用手机号、微信或邮箱登录即可对话。支持深度思考模式切换、文件上传（PDF/Word/TXT）和联网搜索开关。桌面与移动浏览器均可使用，无需安装。

方式二：移动端 App 在应用商店搜索“DeepSeek”下载安装（Android 包约 12M），登录同一账号后与网页端聊天记录互通。手机上发起的对话，回到电脑网页端可继续查看和追问。

方式三：API 调用（开发者） 访问 platform.deepseek.com 注册账号并充值，创建 API Key 后即可通过 OpenAI 兼容格式或 Anthropic 格式接口调用。模型名使用 deepseek-flash 或 deepseek-v4-pro，支持思考模式切换、JSON Output、Tool Calls、对话前缀续写等功能。新账号无免费额度，需首次充值后方可调用。

方式四：本地部署（开源用户） 从 Hugging Face 下载 V4 系列模型权重（MIT 协议），使用 vLLM、SGLang 等推理框架在自有 GPU 环境部署，完全离线运行，无数据外传风险。

【常见问题】

DeepSeek 收费吗？ 对话应用（网页端 + App）完全免费，包含深度思考、联网搜索、文件上传等全部核心功能，无订阅制、无付费墙。API 调用按量计费，价格在同类产品中处于极低水平，且空闲时段价格减半。模型权重开源，可免费本地部署。

Pro 和 Flash 怎么选？ Flash 适合日常对话、简单问答、文档摘要和成本敏感型 API 调用，响应速度更快、价格更低。Pro 适合复杂推理、编程任务、Agent 工作流和需要深度世界知识的场景。网页端对话默认使用 Flash 即可满足多数需求；API 用户可根据任务复杂度在请求中切换模型名。

1M 上下文实际能处理多少内容？ 1M token 约等于 70-80 万汉字，可一次性处理《三体》三部曲体量的长文本、数百页技术文档或完整的中型代码仓库。网页端和 API 均支持该上下文长度，无需分段处理。

国内使用方便吗？ DeepSeek 是国内产品，网页端、App 和 API 平台均可直接访问，无需网络配置。普通用户从网页端或 App 开始即可零门槛使用，开发者通过 platform.deepseek.com 完成 API 接入。
