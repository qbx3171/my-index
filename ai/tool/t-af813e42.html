Codex

Codex 是 OpenAI 推出的 AI 编程智能体，专为软件工程任务设计，可帮助开发者编写、审查和交付代码。它已整合进 ChatGPT 生态，覆盖桌面应用、命令行（CLI）、IDE 插件及云端环境，用户可通过同一 ChatGPT 账号在各终端无缝使用。Codex 最初于 2025 年 4 月推出，后续迭代中逐步强化了多智能体并行、后台运行、技能扩展等能力，定位从单纯的代码生成工具演变为可统筹复杂工程任务的“智能体指挥中心”。

【核心功能】

代码编写与重构：依托 OpenAI 前沿编码模型，可完成功能开发、复杂重构、代码迁移等端到端任务，以更少 Token 交付高质量成果。

多智能体并行：Codex 可同时运行多个智能体，在隔离的代码副本（工作树）中并行工作，避免冲突，并利用浏览器工具验证成果。

自动代码审查：自动审查 Pull Request，指出团队容易忽略的漏洞，解答疑问，让开发者专注于需要判断的核心环节。

云端持续运行：即使关闭电脑，Codex 云端任务仍可继续执行，支持在桌面、网页或移动端启动和继续任务。

技能（Skills）扩展：可将团队规范、工作流程封装为技能，让 Codex 在不同任务中一致应用；也可接入插件执行跨应用操作。

后台自动化：可安排 Codex 处理工单分发、告警监控、CI/CD 等繁琐日常工作。

【订阅与定价】 Codex 已包含在 ChatGPT 各档套餐中，用量限制因套餐而异。

Free / Go：可使用 Codex，但云端功能受限。

Plus：每周提供 Codex 使用额度，适合专注的编程会话。

Pro：更高使用上限，支持全天多项目高强度工作。

Business：共享工作空间，含管理员控制，适合团队协作。

（注：Business 及以上团队的 Codex 具体定价随 ChatGPT 套餐及席位类型变化，建议以 chatgpt.com/pricing 实时信息为准。）

【如何使用】 方式一：ChatGPT 桌面应用

使用 ChatGPT 账号登录 Codex 桌面应用。

在项目线程中描述任务，Codex 会在独立工作树中执行。

在界面中审阅代码变更，可直接评论或跳转编辑器手动修改。

方式二：命令行（Codex CLI）

打开项目目录，运行 codex 命令。

按提示使用 ChatGPT 账户登录。

描述任务，Codex 在终端中执行；新版 CLI 支持智能体视图、多智能体工具、工作树隔离等功能。

方式三：云端

在桌面或网页端创建并发布环境（连接代码仓库、配置依赖）。

在任意设备启动云端任务，即使本地计算机关闭也可继续运行。

【常见问题】

Codex 和普通 ChatGPT 有什么区别？ Codex 是专门针对软件工程优化的智能体，具备代码仓库操作、多智能体并行、自动代码审查等工程化能力，而普通 ChatGPT 侧重对话与文本生成。

Codex 只能写代码吗？ 不止。通过“技能”扩展，Codex 可执行信息收集、问题分析、写作等任务，并能在电脑上模拟操作完成实际工作。

需要额外付费吗？ 不需要单独购买 Codex，它已包含在 ChatGPT 套餐中，用量随套餐等级变化。
