千问

通义千问（Qwen）是阿里巴巴通义实验室打造的全栈式大模型家族与 AI 助手产品，覆盖从轻量化多模态到超大规模旗舰的完整模型矩阵。其核心定位已从基础对话助手升级为“全链路智能体基座”，能够独立完成复杂任务、长周期执行与多模态交互，支撑个人办公、企业服务、科研开发及 AI 应用落地等多元场景。面向普通用户的 Qwen 助手免费开放，同时提供 API 平台供开发者集成，使用与 OpenAI 兼容的 API 格式，降低接入成本。

【核心功能】

原生多模态理解与交互 Qwen 能够同时处理和分析文本、图像、音频、视频等多种类型信息，实现跨模态信息融合推理，而非简单的“图片转文字再问答”。图像场景可解析手绘草图、UI 截图、工程图纸、复杂表格，直接输出前端代码或提取数据生成结论；音视频场景支持会议录音转写、要点提炼、时间戳定位和多语言字幕生成。

百万级超长上下文 最新 Qwen 系列原生支持百万 Token 级上下文窗口，可一次性载入数百页合同、整套项目源码、整本专业书籍或数十份财报，跨章节建立信息关联，精准定位条款、数据和结论，减少长任务中的记忆漂移和幻觉问题。网页端可直接批量上传 PDF、Word、Excel、Markdown、TXT 等格式文件，无需拆分预处理。

智能体（Agent）与长周期自主执行 Qwen3.7-Max 及后续版本致力于成为“全能智能体基座”，在编程、办公自动化和长周期任务中具备自主执行能力。在一项长达 35 小时、超过 1000 次工具调用的全自主实验中保持了连贯推理，验证了持久稳定的执行能力；同时具备跨框架泛化能力，可在 Claude Code、OpenClaw、Qwen Code 等不同框架下稳定发挥。

Deep Research 深度研究 Deep Research 是一个智能代理系统，利用互联网上的大量信息执行多步骤搜索和分析总结，完成复杂任务并输出全面易读的报告，将原本需要数小时的研究工作压缩至几分钟。

Web Dev 自然语言建站 Web Dev 功能让开发者仅通过自然语言描述即可创建包含整洁代码和现代设计的完整网页，无需编程或设计技能即可生成可直接使用的网站。

图像生成与视频生成 Qwen 图像系列（如 Qwen-Image 系列）将文生图与图像编辑整合在同一模型中，支持修改图像、转换风格、从零生成或组合多个元素。平台同时提供万相（Wan）系列图像生成模型和视频生成模型，覆盖图片与视频创作需求。

编程与代码能力 Qwen3.7-Max 在编程方面从前端原型开发到复杂多文件工程均可驾驭，并能通过 MCP 集成和多智能体协作实现工作流自动化。

【如何使用】

方式一：网页端（零门槛） 浏览器访问 chat.qwen.ai 或千问 AI 平台体验页，使用手机号或阿里云账号登录即可对话，桌面、平板、手机浏览器均可，无需安装 App。登录后可在模型选择栏自由切换版本：简单任务选 Flash 版本，复杂推理、长文档处理选 Max 版本。

方式二：App 端 在应用商店下载“千问”App，登录后更新至最新版本（6.9.7 及以上），在对话页点击胶囊按钮或模型选择栏即可切换至最新旗舰模型（如 Qwen3.7-Max）。

方式三：API 调用（开发者） 访问千问 AI 平台（platform.qianwenai.com）或阿里云百炼平台，完成实名认证后创建 API Key，即可通过兼容 OpenAI 格式的接口调用 Qwen 系列模型。新用户完成实名认证后可领取免费额度，每个模型通常独立享有 100 万 Token 的免费额度，有效期 90 天，适用于原型开发、功能验证和学习测试。

【常见问题】

千问免费吗？ 面向普通用户的网页端和 App 端提供免费对话功能，每日有一定使用次数，日常问答、文档解析等需求基本够用。API 方面，新用户完成实名认证后每个模型通常有独立的 100 万 Token 免费额度，有效期 90 天，用完后按量计费或订阅 Token Plan。

千问和通义千问是什么关系？ “通义千问”是模型家族和产品的名称，“Qwen”是模型系列的国际品牌名，面向全球用户使用。两者指向同一技术体系，Qwen 助手（chat.qwen.ai）是面向所有用户的免费 AI 助手入口。

不同版本模型怎么选？ Flash 系列定位轻量高效，适合日常对话、简单生成任务；Max 系列为旗舰模型，侧重复杂推理、编程、长周期 Agent 执行和长文档深度处理；Plus 系列居中，兼顾能力与成本。网页端和 App 端均可在对话界面直接切换，API 用户按任务复杂度选择 model 参数即可。

国内使用方便吗？ 千问是国内产品，网页端、App 端和 API 平台均可直接访问，无需额外网络配置。普通用户从网页端或 App 开始即可零门槛上手；开发者通过千问 AI 平台或阿里云百炼即可完成 API 接入。
